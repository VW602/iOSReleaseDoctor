# Code of Conduct

Contributors and maintainers should participate respectfully, welcome differing experience levels, and keep feedback focused on work. Harassment, discrimination, threats, sexualized conduct, and disclosure of another person's private information are unacceptable.

Maintainers may edit or remove harmful contributions, limit participation, or exclude participants for violations. Enforcement should be proportionate and protect the privacy of affected people. Disagreements about code should be resolved with evidence and constructive discussion.

Report conduct concerns privately to a maintainer using an available private repository contact. This local foundation has no dedicated reporting address yet; do not publish private incident details to obtain one. Maintainers should provide a private reporting channel when the public project is established.
